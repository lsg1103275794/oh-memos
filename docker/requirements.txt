# oh-memos API — production runtime dependencies (Linux / CPU)
#
# Scope: exactly what `oh_memos.api.start_api:app` needs to serve requests in
# tree_text mode. Versions are pinned to the project's own poetry.lock so the
# image matches a resolution the project already tests against.
#
# Deliberately NOT here:
#   torch          — every model backend this image serves is a remote API. Only
#                    the HF LLM, KV-cache activation memory and sentence-transformers
#                    embedder need it, and none of them is used here. With torch
#                    (and sympy/networkx, which only torch requires) gone,
#                    site-packages drops from 1524 MiB to 720 MiB (du -sm). The Dockerfile
#                    build check fails if anything pulls torch back in.
#   markitdown     — only used by the document-parser path (magika +
#                    onnxruntime); read_multi_modal/utils.py degrades gracefully
#                    when it is absent.
#   sentence-transformers — pulled in only by an optional langchain splitter
#                    guarded with try/except ImportError; it would also require torch.
#   pymilvus, redis, pika, pytest — preference memory, scheduler queues and
#                    tests are not part of this image.
