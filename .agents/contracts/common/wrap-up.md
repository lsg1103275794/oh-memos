# 收尾：模块做完时自己清理，不留无用遗留

交付或合并前，对本任务产生的文件逐项处理。文件放在哪里见 [artifacts.md](artifacts.md)。

1. **删**：生成的媒体和图表、逐帧或中间数据、模型或依赖的副本、复制来的测试数据、占位文件、浏览器快照、临时服务器的数据目录、本任务的 worktree 和已合并的分支、`runtime/scratch/` 里本任务的残留。
2. **留**：报告（`REPORT.md`）、指标 JSON、可复现的脚本，以及用户明确要求保留的成品。报告引用的大文件删掉后，在报告开头注明已删除和重新生成的方法。
3. **问**：用户的原始数据、成品、外部只读目录，以及**不是本任务产生的**大目录。不确定就先问，不擅自删除。
4. **核对**：
   - 没有自己启动的服务、后台任务、临时服务器还在运行，没有进程占着端口或独占资源；
   - 本任务的 worktree 和已合并的分支已清掉；`.claude/worktrees/` 下其他会话留下的 worktree 不归本任务，不动；
   - 看一眼磁盘占用。
5. **删之前先看清目标**：Windows 下的 junction 只删链接本身（PowerShell 用 `[System.IO.Directory]::Delete(path, $false)`，或 Python 3.12 以上的 `shutil.rmtree`），绝不跟进去删目标；类 Unix 系统上删符号链接用 `rm` 链接本身，不加尾部斜杠。

最终汇报里写清楚：删了什么、各多大、留了什么、为什么留。
